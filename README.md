# Личный кабинет.

##

Запуск прода, команда из корня проекта:
maker up-prod

Ауторизация на главном экране (.htpasswd файл паролей в корне сайта)
user:user87
password:OzLaks!0a_334:9+

Команда на добавление и изменения пароля:
htpasswd -c ./.htpasswd user87

Проект разбит на модули.
